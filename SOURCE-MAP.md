# Which source each file represents

| Source | Tool example | Included files |
|---|---|---|
| Product context | Website and project docs | [product/](product/) |
| CRM | Attio or HubSpot | [Companies, contacts, deals and owners](data/crm/) |
| Call recorder | Granola or Pocket | [8 transcripts](data/transcripts/) |
| Email | Gmail | [10 threads](data/email/) |
| Prospecting | RowRun | [Thin and researched prospect lists](data/prospecting/) |
| Website research | Context.dev | [12 prepared company-page extracts](data/web/) |
| Contact enrichment | BetterContact | [Prepared matching results](data/enrichment/prepared-results.csv) |
| Exclusion list | CRM or operator sheet | [Exclusions](data/operators/exclusions.csv) |
| Shared materials | Drive, Notion or local files | [Offers, writing examples and brand assets](content/) |

These are file equivalents using the [sample schema](data/SCHEMA.md). They do not require an account with any of these services or demonstrate a live connection.
